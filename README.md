# Star Dino Piano Web Prototype

这是一个先行 Web 原型，用来验证低幼孩子是否喜欢并理解：

- 按屏幕钢琴键；
- 看到小恐龙和故事场景立刻变化；
- 逐步建立 `唱名 / 音名 / 键位 / 五线谱位置 / 听到的钢琴音` 之间的联系。

当前权威规划在 [docs/README.md](docs/README.md)。如果根目录旧素材说明、旧设计草案和 `docs/` 冲突，以 `docs/18_CURRENT_PLANNING_REVIEW.md` 为准。

## 当前定位

- 触屏优先：不连 MIDI、不用麦克风也应该能完整玩。
- Web MIDI：只作为支持浏览器里的可选输入；不要承诺 iPad Safari 可用。
- 麦克风听音：仍是实验/后续能力，不能作为通关或稳定掌握的硬条件。
- iPad 原生 App：等核心玩法验证后再做，届时 MIDI/音频应走原生能力。

## 当前核心内容

- `M01-M08`：月亮小家建造，训练 C-D-E，再预备 F/G。
- `FG01-FG04`：进入五线谱前的 F/G 微练习。
- `S01`：五线谱星桥，小恐龙按谱位跳到对面星球。

`A-G` 英文单词打字玩法已经放入后续计划，不属于当前 MVP。

## 运行

在本目录启动本地服务器：

```bash
python -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173
```

## 使用建议

- 先用屏幕琴键验证孩子能不能看懂“按音 -> 场景变化 -> 小恐龙前进”。
- 先看 `M01`、`M03`、`M08`、`FG03`、`S01` 这些关键切片。
- MIDI 和麦克风只当作可选输入测试，不要让它们阻塞孩子主流程。
