# A-G Word Typing Game Later

## Status

This is a later project. Do not implement it before the core note, key, sound, and staff loops are polished.

## Why It Is Interesting

The seven piano letter names `A B C D E F G` can form simple English words. Pressing piano keys to spell these words could reinforce letter note names in a playful way.

## Possible Game Frame

The dinosaur repairs signs, crates, or spaceship labels by pressing note-letter keys:

- `BAG`
- `BAD`
- `BED`
- `BEE`
- `CAB`
- `DAD`
- `EGG`
- `FACE`
- `FEED`
- `CAGE`

The game should pronounce the word and play the notes, so it is both language-adjacent and music-first.

## Learning Value

- strengthens letter-note recall;
- helps children remember A-G as a closed note alphabet;
- gives older children a different practice mode after C-D-E-F-G basics.

## Risks

- English spelling may be too hard for younger children.
- It trains letter names more than solfege.
- It can distract from staff reading if introduced too early.

## Entry Criteria

Only start this mode when:

- C-D-E-F-G key finding is stable;
- A and B have their own note identity rows and keyboard-locator teaching;
- staff bridge S01 is clear and fun;
- touch listening is reliable, with MIDI/microphone still optional;
- parent view can explain what this mode trains.

This mode should be optional and older-child leaning. It trains letter-name recall, not the core solfege/staff bridge loop.
