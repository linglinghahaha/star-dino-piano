这份文件把“以后找老师和 3-5 个孩子试一试”变成可以执行、可以退回、普通家长也能看懂的流程。它不是医学、心理或正式学术研究方案，也不授权收集儿童声音、人脸、姓名或其他不必要的个人信息。

## 一、这项观察要回答什么

每轮只回答与当前稳定版本相匹配的问题：

1. 孩子第一眼是否看懂故事里发生了什么；
2. 孩子是否知道现在主要要听、找键、按顺序、看谱位还是轮流；
3. 正确钢琴动作是否很快产生可理解的世界变化，以及孩子是否表现出“是音乐让它变化”的联系，而不只是看到了动画；
4. 第一次按错后，孩子能否从温和反馈中修复，而不是靠成人报答案；
5. 唱名、音名字母、谱位和键位是否在本关承担清楚且不重复的职责；
6. 一段 3-5 分钟短课是否有可察觉的小成就和自然休息，而不是变成长练习；
7. 孩子是否自愿继续有意义的音乐动作、在反馈后重新投入，还是只被动配合或在停点前离开任务；
8. M01 的音名字母/黑键组、M03 的声音、S01-mini 的谱位是否各自真正帮助孩子找到琴键，而不是颜色、亮键或成人答案；
9. 家长页面是否诚实地区分玩过、当前稳定和后续保持，而不是把一次完成写成学会。

本协议不能证明：长期学习效果、适用于所有儿童、钢琴技术正确、学校课程替代、医学或认知改善。任何这类宣传需要更强的专业研究和地区合规审查。

## 二、三层证据，不可互相冒充

| 层级 | 最低样本 | 可以说明 | 不能说明 |
| --- | --- | --- | --- |
| 方向性观察 | 1 名 4-6 岁儿童 + 1 名成人记录 | 某个界面是否存在明显理解障碍，哪里需要继续修 | 低龄普遍可用、教学有效或发布通过 |
| 低龄参与与教学流程门禁 | 3-5 名不同的 4-6 岁儿童，分开的短观察 | 核心开始、参与、错误修复、阶段成就、音乐因果、三种表示迁移、休息与下一任务是否成立 | 长期掌握、学习效果、所有设备可靠或最终美术声音已通过 |
| 发布前复测 | 最终美术、动作、声音和真机候选上的新一轮 3-5 名儿童 + 教师复核 | 最终候选没有因美术/声音变化重新制造注意与理解问题 | App Store 一定批准或课程具有经研究证明的学习效果 |

至少一轮观察必须发生在实体 iPad 横屏上。桌面浏览器可以用于早期方向性观察，但不能代替最终设备证据。

## 三、隐私、同意与停止条件

### 默认不收集

- 不记录孩子姓名、完整生日、学校、地址、账号、联系方式或精确位置；
- 默认不录音、不录像、不拍脸，不保存麦克风原始音频；
- 不把孩子的触控、MIDI 或错误历史上传到服务器；
- 不使用观察素材训练、克隆或公开展示儿童声音/形象；
- 不把观察写成对孩子能力、智力、注意力或发展情况的诊断。

### 必须有

- 监护人在场，并在开始前看懂观察目的、时长、记录内容和停止权；
- 使用匿名编号，例如 `C01`，只记录年龄段 `4.0-4.5`、`4.5-5.0` 等必要范围；
- 孩子愿意开始。孩子说不想玩、推开设备、明显烦躁或离开座位时立即停止；
- 成功与否不影响礼物、奖励、家长评价或继续玩其他内容；
- 观察者只记录看见的行为，不写“懒、笨、没天赋”等评价。

项目根当前是有效 Git 工作树，`private-recordings/**` 规则以及 WAV/PDF 探针的 `git check-ignore -v --no-index` 命中均已验证为 `passed`。这只证明私密文件不会被普通提交跟踪，不等于授权收集。用户未明确提供文件、用途授权和唯一接收负责人前，真实授权原件、联系方式及任何可识别观察记录仍须保存在项目外；以后确需接收时，只能进入本机已忽略的 `private-recordings/consent-private/`，仓库中始终只允许去身份化汇总。

## 四、观察环境

- 安静普通房间，不要求专业琴房；
- iPad 稳定放在桌面，横屏，屏幕和实体琴键都让孩子自然够到；
- 音量先由成人试听，钢琴音清楚、角色语音和音效不刺耳且不盖住目标音；
- 触屏路线始终可完成。MIDI 或原声钢琴只在对应路线已经通过真机可靠性检查后加入；
- 关闭通知、来电和与任务无关的应用；
- 使用专门的空白测试档案。每名孩子开始前重置，不继承上一名孩子的提示、稳定记录或故事位置；
- 观察者可以使用外部秒表记录等待，但孩子屏幕不出现倒计时，速度不进入奖励或掌握判断。

一次到访最多安排两个 3-5 分钟观察段，中间允许休息，总操作时间建议不超过 10-12 分钟。不要为了收齐数据强迫孩子把整章玩完。

## 五、成人统一开场和干预等级

### 开场只说

“这是星芽的音乐世界。你可以自己看看、听听，想试的时候就开始。不想玩了随时告诉我。”

进入新画面后，成人先保持安静，让应用自己的角色、道具、声音和动作承担说明。不要先说“按亮的键”“这里是 C”“恐龙要跳过去”。

### 干预编码

| 编码 | 成人做了什么 | 该次证据怎样使用 |
| --- | --- | --- |
| `I0` | 完全没有帮助 | 可用于独立可理解性证据 |
| `I1` | 中性鼓励或应孩子要求重复“可以再看看/再听听”，不读答案 | 可用于低龄门禁，但必须记录次数 |
| `I2` | 只指出操作区域，例如“钢琴在下面”，不指出具体键、音或谱位 | 只能算方向性可用；相同位置被两名以上孩子需要时视为界面问题 |
| `I3` | 读出应用提示、指出准确琴键/谱位或解释本关规则 | 不能算独立完成；需要判断是文字依赖还是任务设计问题 |
| `I4` | 直接报答案、替孩子按键、握手移动或完成步骤 | 本段教学证据无效，但故事仍可温和完成；必须记录停止或退回原因 |

同一问题若两名以上孩子都需要 `I2-I4`，默认是产品问题，不归咎于孩子。成人不要在孩子犹豫几秒后立刻帮忙，应先让应用自己的分级提示运行。

## 六、孩子观察表

每个短观察段记录一行：

| 字段 | 记录方法 |
| --- | --- |
| 匿名编号与年龄段 | `C01 / 4.5-5.0`，不写姓名和生日 |
| 构建与设备 | build id、iPad/浏览器、屏幕尺寸、触屏/MIDI/麦克风路线 |
| 观察关卡与唯一教学轴 | 例如 `M08 / C-D-E-F-G 上行顺序与整段路线` |
| 第一注意点 | 角色、故事问题、可演奏道具、键盘、顶栏、装饰或其他 |
| 第一个有意义动作 | 听、看当前物件、按键、点非任务装饰、求助或无动作 |
| 声音因果 | 目标模型音是否清楚结束后才开放作答；一次触摸/MIDI 是否只听到一份孩子回声音；世界物件是否在孩子回声音结束后才变化 |
| 干预 | `I0-I4`、发生时间点和成人原话 |
| 第一次错误 | 按了什么；应用是否说清刚才的音与目标；已有进度是否保留 |
| 修复结果 | 自己修复、应用提示后修复、成人帮助、放弃或自然休息 |
| 世界变化是否被注意 | 孩子是否看向/说到屋顶、桥、种子、石头、星灯等变化 |
| 主要解题线索 | `note_name_and_black_key_group`、`sound`、`staff_position`、颜色、亮键、猜测、混合或不确定；界面提示除星芽对话外只按音名记录 |
| `engagementSignal` | 记录自愿持续、App 反馈后重新投入、被动配合、停点前脱离、拒绝或不确定，并写看见的行为；不要直接问“好不好玩”代替观察 |
| `achievementResponse` | 记录孩子是否自发庆祝、无需成人就注意阶段结果、继续但未注意、需成人解释或未到达，并写具体动作/原话 |
| `musicWorldCause` | 区分主动预期/说出音乐导致变化、在琴键和变化物之间来回看、只注意变化、未见联系或不确定 |
| `representationTransfer` | 固定记录本路线目标、结果、是否确认无答案型干扰线索及行为证据；按对本身不算迁移证据 |
| `paceFit` | 记录有余力地自然停下、主动想再来一个短段、需要提前休息、停点前脱离、过度刺激/疲劳或不确定 |
| 结果与休息 | 是否察觉阶段小目标的场景结果；是否无需“关闭/下一关”说明就自然停下 |
| 主动继续 | 主动想继续、接受继续、想休息、想离开；不作为分数 |
| 观察备注 | 只写可观察行为，不做诊断 |

观察者不得仅凭孩子按对就推断他使用了哪个线索。要判断颜色依赖，应使用已批准的减色版本或后续不同线索的迁移任务，而不是询问诱导性问题。`engagementSignal` 也不是给孩子打“有趣分”：安静专注可以是参与，夸张庆祝不是必需；只记录主动动作、重新投入、离开任务、请求继续或请求休息等行为。

## 七、分阶段观察路线

不得把下列路线一次塞给同一个孩子。每一阶段只在对应运行版本已经通过自动化和主管审查后开放。

### A. 第一、二章教学纵切

| 观察段 | 重点 | 建议内容 | 通过前必须看到 |
| --- | --- | --- | --- |
| `OBS-A1 音名与键位` | 界面音名 `C -> 两黑左 -> C4` 的联系；唱名只允许出现在星芽对话里 | `M01`，必要时另一次 `M02` | 不靠颜色或成人指出准确键；音名字母与黑键组共同支持第一次找键 |
| `OBS-A2 听到音再找键` | 听到 `Re/D` 后找到 D4 | `M03`，单独短段 | 目标音完整结束后才可回答；一次按键只听到一份孩子音；错误后按“孩子音 -> 目标音”无重叠比较；轮子只在孩子回声音结束后安装 |
| `OBS-A3 可演奏施工谱` | 五音上行顺序直接改变屋顶 | `M08` guided；只有状态轻松才自然进入 seal | 每 1-2 个输入注意到真实屋顶进展；第二遍不是拆屋重做；吃力时能在闭合屋顶休息 |
| `OBS-A4 五线谱桥` | 谱位、键位和角色跳跃的联系 | `S01-mini` 的 `C-D-E`，以后再观察完整 S01 | 五条线和当前垫可辨；无答案字母/目标亮键时能从谱位找到键；知道恐龙到达了哪里 |

第一轮方向性观察不要求同一孩子完成 A1-A4。低龄门禁必须由 3-5 名孩子整体覆盖 `M01`、`M03`、`S01-mini` 三条路线；每条路线至少形成一次无 `I2-I4`、无答案型干扰线索的对应表示到琴键证据，并至少有一名孩子经历真实错误与修复。M08 可以补充故事节奏观察，但不能替代这三条迁移路线。

### B. 第三章听音花园

- `LS01-LS03` 只观察“听、模仿、叶片永久打开”和自然停点，不写 listening stable；每个动作都必须先真实播放一声可见模型，孩子回声结束后叶片才变化，一次触摸或 MIDI 不得出现通用琴键声与受控回声双响；
- `LS01-LS03` 的错误比较按“孩子刚按的音 -> 当前目标音”播放且两声不重叠，比较结束前不能再次评分；若模型音、孩子回声或 modeled 音被系统打断，植物不得静默长成；
- `LS04` 单独观察隐藏 Do/Re 比较，两个固定中性声音源必须同权重，作答前无字母、键位、角色发光或位置泄题；
- `LS05-LS08` 分批开放，不让一个孩子在一次到访完成整个听音章；
- 观察重听是否帮助记忆，还是被孩子当作反复触发特效；
- `LS08` 只允许整组重听的稳定检查必须在运行门禁先通过后观察。
- proposed `C3-X01` 声音到谱位短课当前只有 `docs/57` 规格，教师复核、正式课程插入和 runtime 都未通过，不能进入儿童观察。以后获准时必须单独观察谱位首选与琴键首答，不能只看最后琴键是否按对。

### C. 第四章低音与低音谱表

- `LP01` 只考高低听觉比较，使用两个固定中性触屏声音泡泡；成人不得让孩子去找 C3 键回答；
- `LP02` 才观察同名不同音区和准确 C3 键位；
- 双八度键盘必须保持真实连续几何，观察孩子是否能利用两组黑键而不是把低 C 当成另一个颜色按钮；
- 低音谱表观察分开进行，不能同时引入新键位、新谱位和左手技术要求；
- “左手使用”只由成人现场观察记录，不能由音高推断。

### D. 第五章接力与可选合作

- 所有孩子先完成核心 TH08 relay 并得到完整花园；核心结束前不得出现 TH06/TH07 邀请，不会同时按两个音也不欠任何故事内容；
- `TH05` 按两座桥墩、近端四灯、远端四灯、第一段信号、第二段信号分五次到访保存；每次只有 2/4/4/5/5 个输入。观察孩子回主页后能否说出或指向唯一下一动作，恢复时是否知道已完成部分没有消失；
- 观察 TH08 第一次把两段连起来时，孩子是否感到“终于让整座桥唱起来”，而不是觉得又被要求机械重复刚完成的十步路线；
- core TH08 完成画面先自然停留，同一 session 的 optional session 数必须为 0；后来新的主页到访才可把 TH06 作为唯一当前邀请；
- `TH06 -> TH07 bar 1 -> TH07 bar 2 -> TH08 together-encore` 只在孩子后来明确点击后逐段开始；拒绝、返回、散开按下、麦克风或单点输入时顺序完成或延期，不出现失败、补考感或差奖励；
- 观察孩子能否理解 TH06 的 C/C、G/G、C/C 是“一起落地”练习，TH07 才把经验迁移到真实第二小节 G3+E4，而不是把 G/G 误当作品内容；
- 至少分别观察 core relay 和 later optional，确认花园、角色认可和收藏早已由 core 完成，optional 只增加临时音乐层且不重播解锁；
- 配对毫秒只供成人技术记录，350/600ms 在教师与真机确认前标 provisional，不在孩子屏幕显示，不用于速度压力或能力分档。

## 八、教师复核表

至少邀请一名熟悉幼儿钢琴启蒙的教师。教师既看课程文件，也实际操作当前候选，逐项给出 `通过 / 需修 / 无法判断`：

1. 音高、音区、唱名、音名字母和五线谱位置是否准确；
2. `C4-G4`、`C3-G3` 与中央 C 的术语是否不会误导；
3. 每个短课是否只有一个新教学轴，旧知识只作为支架；
4. 提示递减是否从示范到定位再到少提示，且不会让孩子只追亮键；
5. 第一次错误是否命名刚按/听到的音，再比较目标，而不是只说“错了”；
6. 一次短课的输入量、重复次数和自然停点是否适合 4-6 岁；
7. 听音关是否真正隐藏答案，模型音是否完整结束后才开放作答，一次输入是否只产生一份孩子回声，错误比较和世界动作是否遵守声音先后；
8. 五线谱、低音谱表和两手路线是否没有提前引入过多概念；
9. 52 BPM、350/600ms 等制作阈值是否需要调整；
10. `played/stable/retained` 与家长文案是否诚实，不把一次完成称为掌握；
11. 故事奖励是否帮助理解音乐因果，而不是遮盖教学音或诱导乱按；
12. 产品没有用角色、颜色或文字替代真正的声音、键位和谱位学习。

教师提出修改时必须写明受影响的 level id、事实依据、严重度和需要重跑的门禁，不能只写“感觉不适合”。主管将问题分为：

- `P0`：错误音高/谱位、伤害性提示、隐私/版权或会形成明显错误音乐概念；立即停止相关路线；
- `P1`：多数孩子可能无法理解、任务包含两个新轴、错误修复教错或掌握声明不诚实；当前里程碑退回；
- `P2`：不阻断核心学习但应在发布前改善；进入下一里程碑；
- `P3`：个人偏好或需更多证据；记录观察，不立即改动。

## 九、低龄参与与教学流程门禁怎样裁决

3-5 名儿童的整组结果只有同时满足以下条件，才能形成主管待审候选；它不是自动 `passed`：

1. 至少 3 名孩子无需 `I3/I4` 完成一个有故事意义的短段；
2. 没有两名以上孩子在同一位置需要成人指出操作区或答案；
3. 整组至少观察到一次真实错误，并证明应用反馈后孩子能修复且进度不倒退；
4. `M01`、`M03`、`S01-mini` 三条路线都至少被一名孩子真实观察；每条路线至少有一次 `I0/I1` 且确认无答案型干扰线索的对应表示迁移；
5. 至少 2 名孩子出现自愿持续或在 App 反馈后重新投入的参与信号，不能把被动配合计为“好玩”；
6. 至少 2 名孩子无需成人解释就注意到本段阶段成果；
7. 至少 2 名孩子表现出音乐动作与世界变化的联系；只看见变化不够；
8. 至少 2 名孩子在自然停点仍有余力或主动想再来一个短段；需要提前休息可以诚实记录，但不能被改写成正向节奏证据；
9. 阶段完成后至少 3 名孩子无需 `I2-I4` 找到唯一下一任务；
10. 没有孩子必须阅读长句或英语单词才能知道主要动作，也没有倒计时、扣星、失败页、强制下一关或更差奖励造成压力；
11. 若孩子使用 modeled/assisted 完成，故事可以通过，但该次不能被统计为独立 stable、retained 或学习效果证据；
12. 当前美术、声音或布局之后若发生会改变注意点的重大修改，必须复测。

若样本不足、成人干预记录缺失、版本不一致或只有成功截图，没有过程记录，状态只能是 `partial` 或 `missing`。

## 十、保持性与学习效果的诚实边界

- 同一次到访的重复成功不能证明 retained；
- App 内 retained 仍必须遵守 `docs/31` 的不同 session、不同本地日期和至少 8 小时条件；
- 若要对外声称孩子经过本产品形成了保持性学习，需要安排后续到访、使用少提示提取任务并记录成人干预；
- 3-5 名可用性观察仍不足以支持“显著提高识谱能力”等效果宣传；此类主张需要独立研究设计、对照和专业合规审查。

## 十一、交付与归档

每轮外部观察交付：

1. 冻结 build id、设备、输入路线和音量/减少动态设置；
2. 匿名逐段观察表；
3. 成人干预原话与编码；
4. 教师逐项表和受影响 id；
5. `passed / partial / missing / contradicted` 汇总；
6. P0/P1 合并退回单和需要复跑的自动化/截图/真机门禁；
7. 明确哪些记录留在项目外，哪些去身份化摘要可以进入项目。

正式汇总可以记录在未来的 `docs/external-evidence/`，但该目录不得包含姓名、联系方式、脸、原始声音、授权原件或设备账户信息。Git 与忽略规则已通过，但录音和可识别观察资料的接收门禁仍为 `closed / not requested`；没有用户明确授权和唯一负责人时，不创建或接收这些文件。

## 十二、当前结论

- `passed_spec_r2`：观察目标、成人干预编码、三路线覆盖、参与/成就/因果/迁移/节奏字段、教师清单和隐私边界已形成可执行协议。
- `missing`：教师、家长和儿童尚未招募；没有实体 iPad 观察；没有任何路线达到 3-5 名儿童证据。
- `historical_browser_candidate_frozen`：`overhaul-354b-parent-data-reset` 的 46 文件 manifest 和精确哈希继续保留浏览器历史证据；品牌、R01B、麦克风释放与家长清除均有效。但 `docs/65` 新确认的视觉 P0 使该候选退出儿童观察资格，不能再把“manifest 字节通过”写成“可开始预听/观察”。
- `observation_hold`：`observationAllowed=false`。UI-P0A/P0B/P0C、M08 可追溯姿势与 359A 主页返回门禁已通过；下一道门禁是成人在实体 iPad Safari 核对 `359a · 5AB01914` 并确认横屏、目标钢琴音、音量和遮盖。旧版本、失败或无法确认时不得让孩子开始。
- 早期方向性观察只覆盖 manifest 冻结且有对应浏览器门禁的路线；不能外推到 `C3-X01`、LP05+、第五章、最终美术声音或发布效果。
- `release blocked`：最终美术/声音后的 3-5 名儿童复测、教师复核、真机和合规证据缺失时，项目不能称为成熟 App。
