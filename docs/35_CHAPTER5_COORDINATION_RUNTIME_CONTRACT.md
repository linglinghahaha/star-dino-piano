## 给家长看的简短说明

第五章先让咚咚和星芽一个说、一个答，再轮流修桥。所有孩子都先用接力方式完成同一座大家园，不需要会同时弹。以后再次到访时，孩子可以尝试一起落地和两小节双层加演；这只是额外体验，不是能力等级，也不会重开或升级结局。

系统能验证音高、音区、顺序、松开重置和时间差，不能仅凭音高判断孩子真实用了哪只手。家长端必须区分“提示过左/右手”“角色/音区接力稳定”“尝试双音”和“成人实际观察到的手部使用”。

森芽星是当前生态星球的正式名称。第五章发生在森芽星可呼吸花园中继台和地下生态层的本地控制区，远端月亮前哨通过地图信号与自动桥模块响应。星芽不无头盔返回真空月面；咚咚和星芽都留在森芽星的安全区域。

## 四、唯一两小节原曲

所有文件和运行实现使用同一首原创两小节，不得临时更换旋律：

| 声部 | 第 1 小节 | 第 2 小节 | 角色工作 |
| --- | --- | --- | --- |
| 星芽/中音 | `C4 q, D4 q, E4 q, D4 q` | `E4 q, D4 q, C4 q, C4 q` | 每拍点亮一颗星 |
| 咚咚/低音 | `C3 w` | `G3 w` | 每小节第一拍放一个支撑 |

- 拍号 `4/4`；引导目标 52 BPM，允许 48-56 BPM 作为制作范围。4/4、音符时值和 48-56 BPM 只属于成人/教师与实现参数，孩子端不教学、不显示、不评分；它们不产生 rhythm played、stable 或 retained 证据。
- 探索、分声部和核心接力不因速度失败。慢脉冲只帮助轮次和分组，不是排名。
- TH05 relay：每次 session 只做一个 bar；咚咚先弹低音锚并可在回答前松开，星芽按自由但清楚的四音顺序回答。TH08 才第一次把两个已学 bar 连成完整演出。
- later TH07/TH08 together-encore：只有两个小节第一拍要求尝试配对；其余中音顺序单独接收。
- 低音提前松开只写 lowReleaseObservation，不失败、不要求踏板、不声称延音掌握。

## 五、轮次和配对状态机

### 核心接力

1. `role-ready`：只显示当前角色和当前 register 标签；TH01/TH02 不显示 hand prompt，TH03、TH05 和终章后的 optional 阶段才可按各自合同显示一枚孩子视角手邀请，手始终不参与判错。
2. `pulse-ready`：慢脉冲到达，但没有倒计时失败。
3. `awaiting-note`：接收当前 register 的目标音。
4. `correct-turn`：当前桥段/灯立即变化，切换下一角色。
5. `wrong-note`：说出孩子音，保留轮次，给当前键位修复。
6. `right-name-wrong-register`：字母正确但来自另一个同名音区时，记录 `noteNameCorrect=true/registerCorrect=false/roleTurnCorrect=false`，说明“名字对，这次轮到哪个家”；不把物理用手当成证据或错误。
7. `assisted/modeled`：共同完成当前轮次，保留故事，阻止本次 stable。
8. `permanent-rest`：保存桥段并停止 autoplay。

第一次 guided route 只写 played，不写 stable。以后独立慢脉冲 review 观察角色/音区顺序，不判断真实用手，也不要求精确 BPM；六个 exact-register first response 必须依次正确，最多一个 `pulseMiss`，且 strong cue、modeled success、模型音或持续目标键光都会阻止 stable。

### 可选 paired window

- 每个 pair 有 low/high 两个 register-qualified target；顺序不重要，必须是两个离散起音。
- 第一音到达后打开 pair window；第二音在暂定 `<=600 ms` 内可触发友好一起落地动画。
- 成人 emerging paired timing 观察暂用更严格的 `<=350 ms`、TH06 至少 2/3 pair 达标；阈值版本必须记录，教师和实体设备确认前不得称为 validated 或 stable。
- `351-600 ms` 只触发友好故事效果，不写 stable paired timing。
- `>600 ms`、只有一个音、设备不支持或孩子改为顺序弹，都走 sequential fallback；同一拱门仍点亮。
- microphone route 不产生 pair evidence；程序自动音、长按重复、MIDI 抖动和未重新武装输入不能补第二音。

## 六、TH01-TH08 精确职责

### TH01-TH02 同名呼应

- TH01 新轴是角色/音区轮次，不是物理手轮次；C3/C4 同名关系已经在 Chapter 4 教过，只作可见、可听的故事定锚，不作为新知识检查。
- TH01 固定低 C3、后中央 C4。每轮必须等角色短句结束，再播放一个完整模型钢琴音，显示当前字母与准确两黑键组定位，随后才开放响应；未来 C 键、另一个角色和下一音不得获得答案权重。
- TH02 固定先 G3、后 G4，再以 C3、C4 收束。G3/G4 是有提示迁移：每轮可播放一个模型音并显示当前三黑键组定位；孩子普通标签固定为 `低音 G`、`上面的 G`，禁止 `中央 G`。返回 C3/C4 是同 session reduced-cue transfer：不播放目标模型音，不显示目标键光、颜色答案或未来键预览，只保留当前角色和 `低音 C`/`中央 C`。
- TH01/TH02 不显示 hand prompt，`handPrompted=false`。孩子用任意手或同一根手指按到准确目标都正确，默认 `actualHand=unknown`；pitch、touch、MIDI、microphone 都不能把角色音区自动翻译成真实左右手。
- Smooth route 在同一 session 从 TH01 自动衔接 TH02，无 modal 或结算。TH01 repeated repair/strong/assisted/modeled、长等待或疲劳后在 C 信号休息；下一次只进入 TH02，可先自动播放一次不计分 C3-C4 角色定锚，但不重做 TH01 输入或奖励。
- TH02 G pair 出现上述困难时，在永久 G 信号休息，下一 session 只续 C3-C4 返回；地图暂停和刷新保存当前 pair、turn、wrongCount、cueStrength、child inputs 与已接通信号。跨 session 可以完成故事，不能拼接 stable。
- TH01/TH02 只要全部六个故事轮次真实呈现并由 child/guided、assisted 或 modeled 诚实解决，就可写 played；assisted/modeled 保留 `needsPractice`，不回填 child correct/firstTry/inputRoutes。TH02 同 session C 返回只作 transfer observation，不写 stable。
- later opening review 必须是 scheduler 在未来选择的新 session：C pair 与 G pair 各一次，pair 顺序由受约束 seed 选择且不固定复制教学顺序；四个 first response 都必须 exact register，且全程无模型音、strong locator、目标键光、颜色答案、modeled input 或跨 session 拼接，才可写 same-name register/role stable。它不写 actual hand；retained 仍需更后不同本地日期且至少 8 小时的合格 opening review。

### TH03 交替修桥

- 固定精确路线为 `C3/48 -> C4/60 -> D3/50 -> D4/62 -> E3/52 -> E4/64`；咚咚承担低音轮次，星芽承担上方轮次。普通孩子标签使用 `低音 C / 中央 C / 低音 D / 上面的 D / 低音 E / 上面的 E`，键帽本身仍只写字母。
- 第一次只呈现一条 free-time 六音路线，没有 pulse、BPM、速度或 timing stable。每个目标需要一个离散 note-on 和之后的 note-off/rearm；程序重复、长按、MIDI 抖动或未松开的同音不能推进下一轮。
- 一次只显示当前角色/音区和一枚可选的孩子视角左右手邀请。任意手、非邀请手或同一根手指按到当前 exact key 都正确，`actualHand=unknown`；系统不得生成“换错手”错误。
- wrong letter、right-name-wrong-register 和 future-turn target 分开记录。按到未来路线中的音不能跳步；同名字母错音区先肯定字母，再指出当前角色/音区。
- C、D、E 是三个 pair checkpoint。每个单音只移动半段材料，完整 pair 才锁住永久桥段；repeated repair、strong/assisted/modeled、长等待或疲劳只在完整 pair 后休息，恢复只续第一个未完成 pair。
- 全六轮由 child/guided、assisted 或 modeled 诚实解决可完成故事；帮助路线保留 `needsPractice`，不回填 child correct/firstTry/inputRoutes。first play、partial、resume 和跨 session 拼接都不写 stable。
- later review 必须是 scheduler 以后选择的新 session：同一路线六个 exact-register first response 依次正确，无模型音、strong locator、目标键光、modeled input 或跨 session 拼接，且最多一个宽松 `pulseMiss`，才写 `role-register relay stable`。这仍不写真实用手。

### TH04 大谱表会合

- 只解决两个已知 C 的 exact staff landmark 到 exact keyboard home：先是 bass-staff second-space `C3/48`，完整结束后才是 treble-staff ledger-line-below `C4/60`。
- 每轮只显示一个当前谱位、一个当前字母/音区和连续双八度键盘。已完成 C3 可以留作低强调世界结果，但不能继续作为活动答案；不同时教 C4 的 bass-ledger alternate spelling。
- 暂停角色轮次、左右手邀请、pulse、节奏、长旋律、simultaneous 和新谱位选择，避免同时增加多个轴。
- wrong letter 只修当前 C；right-name-wrong-register 记录 `noteNameCorrect=true/registerCorrect=false/staffToKeyCorrect=false`，先肯定名字，再用当前谱位和黑键组定位修准确八度。C3/C4 不合并 mastery id。
- 两轮 guided completion 只写 `C3/C4 staff landmarks played`、帮助强度和 needsPractice，不写 grand-staff stable。later reduced-cue review 必须在新 session 中取得 2/2 exact staff-to-key first response，并且无模型、strong locator、目标键光、modeled 或跨 session 拼接，才写这两个 C landmark stable。
- 会合灯只出现一次。clean formal TH04 可以触发本 phase 唯一轻量 milestone；assisted/modeled 只完成故事和打开 TH05，不显示 clean milestone。

### TH05 多阶段建主桥

- `C5-04A` 只弹 C3/G3，两音必须离散 release/rearm，不要求保持四拍；两座桥墩分别落下，完成后结束 session。
- `C5-04B1` 和 `C5-04B2` 各自先完整播放一个四音模型组，模型 ended 后才开放响应；孩子按当前字母逐颗点灯，未来键不预亮。轻柔无固定音高 pulse 只帮助看清四个位置，不因 timing 失败。
- `C5-04C1` 和 `C5-04C2` 各只组合一个已完成 bar，分别为五个顺序事件窗；低音锚可先松开，不要求 pedal、sustain、simultaneous 或四拍保持。每个输入都需 release/rearm。
- 每个 action 都有独立明确的永久结果和主页连续文案；完成后不附加 check、奖励题或下一 action autoplay。
- 每座桥墩、单颗星灯、relay step 和桥段都持久保存。下一 session 不播放“重新安装”动画，帮助路线也不清空已完成工作。
- TH05 首次 supports/high-bar/relay 只写 component played/order 和帮助来源。它不复用 TH03 六音 stable 门槛，也不写 paired timing、sustain mastery、actual hand 或 two-measure stable。

### TH06-TH08 终章顺序与加演公平

- 第一次 TH08 固定为 core relay finale，并在任何 paired 邀请前写入唯一 `storyCompletion/sharedGardenOpened/finalBridgeBuilt`。TH05 后只有这一个当前入口。
- TH06 只能在 core TH08 正式 ended 后的后来主页到访出现；同一 core completion session 内 optional session 数量为 0。
- TH06 用 `C3+C4 / G3+G4 / C3+C4` 的同名字母组合隔离 paired onset；paired 与 sequential fallback 使用同一练习拱门和永久状态。
- TH07 每个新 child-started session 只练一个已知 bar；不先完整重练两个声部再合奏，也不依据 TH06 timing 决定孩子价值或故事资格。
- 后来的 TH08 `mode=together-encore` 只作加演。困难时当前 pair 顺序完成或在小节边界延期，不重新通过 TH05、重放首次解锁或创建第二个结局。
- core 与 encore 分存 `coreFinaleRoute=relay`、`encoreStage`、`pairedTiming`、`togetherAttempted`；optional 永远不能覆盖核心故事记录。
- 核心 finale 的远端月亮前哨在地图上亮起，星芽和咚咚在可呼吸花园中继台会合庆祝；任何模式都不得让无头盔角色跑到开放太空桥中央。

## 八、输入路线

### 触屏

- 核心 relay 必须完整可玩；花园完成后的 optional paired 可以尝试可靠多点，异常时原位转为 sequential fallback，而不是隐藏奖励或判错。
- 两个同时目标使用真实键位，不扩大或移动键来降低难度。
- pointer/touch 必须离散去抖；一个长按不能生成多音或第二 pair 音。

### MIDI

- 精确 MIDI、note-on/off、velocity-zero 和设备抖动去重。
- 支持 paired timing，但不能证明手 identity。
- 外接琴自身发声与应用音频双响需真机听审。

### 麦克风/真钢琴

- 只支持 sequential core played；不支持 paired/together 证据。
- TH01/TH02 只有在 octave/register 置信度足以区分 C3/C4 或 G3/G4 时，confirmed 结果才可推进 played；octave-ambiguous/uncertain 只写 observation，不算 wrong，并立即保留触屏路线。麦克风不得形成 same-name register/role stable。
- 不上传、不保存原始家庭录音；uncertain/noisy 不算 wrong。
- 麦克风路线遇到终章后的 TH06/TH07/encore 自动使用 sequential fallback；核心故事结果早已完成，optional 不产生 paired evidence 或新结局。

## 九、音频、节拍和反馈

- 教学钢琴音最高优先级；角色语音在目标起音前结束，前 540ms 不被环境、Foley 或奖励动机遮盖。
- TH01 和 TH02 的 G 引导轮必须遵守 `角色语音 ended -> 模型钢琴音 started/ended -> response window open`；TH02 返回 C 轮不得偷偷播放目标模型音。孩子正确输入的钢琴音结束后，信号灯、桥材料和 Foley 才进入。
- TH03 first play 的 pulse 调用必须为 0。later review 和 TH05 的慢脉冲可以是无稳定音高的轻触感/视觉脉冲，不与 C-G 音高混淆。
- TH05 B1/B2 的完整模型四音必须在 response window 前结束；模型音与孩子音不重叠。C1/C2 只组合已经学过的材料，不再播放完整目标 bar 作为逐步答案。
- metronome/pulse 音量低于钢琴，声音关闭后仍有清晰角色轮次和视觉拍点。
- correct-turn 只短确认当前角色；wrong-turn 不播放羞辱音或大红失败层。
- paired success 可增加短暂双层光/无稳定音高 Foley；不能产生更响、更长、更稀有的完成动机。
- core relay finale 负责唯一完整花园解锁；later together-encore 只在已打开花园中提供同等长度的临时音乐层，不重播解锁、不增加角色认可或永久场景。
- 减少动态模式保留键压、当前角色轮廓、桥段静态落位和最终花园；去除连续粒子、快速镜头和持续跳动。

## 十、孩子端界面要求

- 一屏只有一个当前角色/音区、一个当前音乐工作、一个故事道具和连续键盘；手邀请只从 TH03 开始按各关合同出现。任意手或单指完成不得触发错误。
- TH01/TH02 的公开任务名固定为 `两个 C 说你好`、`G 回声接力`；普通轨道与桥灯使用 `低音 C`、`中央 C`、`低音 G`、`上面的 G`，不得显示错误的 `中央 G`、普通 `两个 Do`、`Sol 回声接力` 或字母/唱名双标。
- 两条角色轨道只能在 TH03/TH05 relay/终章后的 optional together 中出现；非当前轨道退为背景，不同时显示两套答案。TH03 普通标签固定为低音/中央或“上面的”字母身份，不显示科学音高或普通唱名。
- TH04 大谱表和双八度键盘不能互相遮挡；一次只有一个活动谱位。bass second-space C3、treble ledger-line-below C4 和会合灯尺寸稳定，完成的前一谱位只作低强调世界状态。
- TH05 的阶段地图由桥墩、两组四灯和主桥表示，不用文字任务清单或卡片套卡片。
- TH05 主页一次只暴露当前内部 action：`放下两座桥墩 -> 点亮近端四颗星 -> 点亮远端四颗星 -> 送出第一段信号 -> 送出第二段信号`。完成 C2 后只暴露 core TH08；TH06 只能在花园已完成后的后来到访出现。TH06、TH07 bar 1、TH07 bar 2 和 together-encore 每次也只能由课程导演选成一个当前任务，不能与核心终章、自由练习或彼此并列成按钮网格。
- optional 邀请使用角色动作和练习拱门，不显示 easy/hard、奖励稀有度或“高级挑战”。
- 完成后无必须关闭/下一关按钮，花园保持可看并允许停止。
- 无文字模式仍可从角色轮次、手图标、桥段移动和键盘理解当前动作。

## 十一、必须自动验证的门禁

1. Story mode 只有真实 LP10 played、bounded-assisted 或 modeled story completion 才出现 Chapter 5；modeled 保留 needsPractice 且不写 child correct/stable/retained、不触发 clean 结算；direct/debug、partial 和未结束 session 不伪造前章证据。
2. 未稳定低音技能只增加支架，不阻止 TH01 或 core relay。
3. C3-B4 连续键盘在三种 iPad 横屏与较小视口不拆行、不分页、不横向滚动，黑键真实。
4. TH01 repeated repair/strong/assisted/modeled、长等待或疲劳后在永久 C 信号休息；下一 session 只进入 TH02，不重做 TH01 输入、奖励或 evidence；可有一次不计分自动 C 定锚。
5. TH01/TH02 同时只显示当前角色和当前 register，hand prompt 数量为 0；未来响应键不强亮，任意手/单指按对不得判错或写 actualHand。
6. TH03 固定六轮次，wrong-note、wrong-register 与 future-turn 分开，桥段不倒退；非邀请手按对不得判错或写 actualHand。

17. together-encore 无二次解锁、phase settlement、独占物件、徽章、台词、结局、稀有度或更高奖励音。

## 十二、人工和真机证据

自动化不能证明：

- 真实 iPad 多点同时按键是否可靠、误触和延迟是否适合儿童；
- MIDI 键盘 paired timing 与应用/琴自身双响是否舒适；
- 4-6 岁孩子是否理解“轮到谁”，是否会被两条角色轨道分散；
- 4-6 岁孩子能否把 `低音 G` 与 `上面的 G` 理解为同名字母的两个键位，而不会把角色、左右位置或手图标当成唯一答案；
- TH01 两音模型、TH02 G 两音模型和返回 C 的少提示迁移是否形成清楚的“教一次 -> 换一个名字试 -> 回到熟悉名字”结构，而不是四到六次亮键模仿；
- 孩子能否把 TH05 的五次独立到访理解为同一座桥逐步完成，并在每次 2-5 个输入后感到有成果而不是被切断；
- 两个 high bar 先听后逐颗点灯是否清楚，TH08 再把两个 relay bar 连起来时是否像“完成演出”而不是机械重复；
- 所有孩子先得到 core TH08 结局以后，后来 optional 邀请是否被理解为“新加演”而不是补考或能力分档；
- TH06 的 C/C、G/G、C/C 是否先降低找键负荷，TH07 再迁移到真实 G3+E4 是否清楚；
- 幼儿钢琴教师是否认可 52 BPM、暂定 350/600ms 窗口、core TH08 十输入负荷和低音提前松开处理；
- 成人是否观察到真实左右手使用、身体姿势和不适。

至少进行：核心 relay 路线 3-5 名儿童观察，确认花园在 paired 邀请前已经完整获得；later optional paired/together 只对愿意的孩子方向性观察，确认顺序 fallback、延期和 together-encore 都不会改动既有结局、角色认可或收藏。
