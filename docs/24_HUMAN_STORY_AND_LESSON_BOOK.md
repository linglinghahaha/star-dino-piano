# 《星芽与咚咚的音乐星桥》故事脚本与亲子教案

这份文件是给普通家长、老师和美术人员看的，不要求读者懂产品术语。它先讲故事，再说明每一关孩子在做什么、为什么这样设计。

当前状态：第一章和第二章 S01 已有 Web 原型；第一章 M03 已实现为第三章听音玩法的预备体验，但第三章正式课程 LS01-LS08 尚未实现；第四、五章也尚未实现。先前两张 SVG 已降级为内部结构线框，不作为正式美术展示。正式界面、动效、音效和生图素材由“星龙工坊原型开发、界面”任务制作；本文件只负责把故事、教学动作、角色反应和验收要求讲清楚。

## 一句话讲清这个故事

原创小星芽龙乘飞船来到月亮，从一座还没有空气的小前哨开始建立太空新家园。它沿着会发光的五线谱桥出发，找到可以呼吸的花园、会唱歌的种子，又从地底的低音中遇见三角龙咚咚。两个朋友先轮流弹，准备好以后再试着一起弹，最后把两个安全住处连成一座会唱歌的大家园。

孩子不是为了拿分数而按琴键。每一个正确的音都会让这个世界发生一件看得见的事：地板落下、种子发芽、脚印亮起、恐龙跳跃、桥梁生长或花园开放。

## 家长怎样理解“玩”和“学”的节奏

一次正常游戏只做一个主要新目标，通常持续约 3-5 分钟。孩子先看到一个具体故事问题，再摸一摸、听一听或看一次示范；接着用 2-4 个很短的音乐动作解决它；如果状态合适，再用一次少提示的小挑战完成最后一块或最后一跳。世界发生永久变化后，角色自然停下来，游戏不自动把孩子拖进下一长串练习。

每个环节都有不同作用：第一次探索是教学，不是假装考试；少提示小挑战才用于判断本次是否更独立；隔了真正休息、另一天再次完成，才可能称为又想起来了。孩子需要帮助时仍然可以修好世界、得到完成感，但家长记录会诚实写成“在故事帮助下玩过”。详细规则见 `33_GAME_TEACHING_PACING_AND_MOTIVATION_CONTRACT.md`。

## 五章故事，用普通话讲

### 第一章：月亮小家

星芽刚到月亮，外面没有空气，脚下也空空的。它穿着完整气密探索服，孩子在琴键和任务物件上认 `C、D、E、F、G`，星芽再用 `Do、Re、Mi、Fa、Sol` 和它们建立口语联系，一起放地板、点灯、修轮子、搭桥和盖屋顶。屋顶闭合、压力灯亮起后，这里才成为安全前哨；但星芽马上还要去外部准备星星桥，所以第一、二章始终保持完整密封，不在中间反复开盔换装。孩子先认识音的名字，再记住它们在黑键旁边的家。

### 第二章：星星桥

星芽看见远处有一颗可能适合生活的小星球。两颗星球之间没有路，只有五条发光的线。星芽继续穿着完整气密探索服；音符变成桥上的落脚垫，孩子在键盘上找到相同的音，星芽就穿过开放太空跳到那个谱位。这只是让一个探索者先过去查看的临时星光路线，还不是能让两个住处长期连在一起的家园桥。

### 第三章：会听的小种子

桥那边有一座小花园。星星背包先检测空气，确认安全后，星芽自动打开头盔、收好外层压力服。种子不会说话，只会唱一个钢琴音。孩子先听，再去键盘上找。找到以后种子发芽。最后，一颗种子唱出比平时低很多的 Do，地面跟着震了一下。

### 第四章：咚咚的低音星球

低低的声音打开了地下洞穴。星芽先听见一个声音，后来看到一团剪影，最后才遇见圆圆的三角龙咚咚。咚咚的家需要低音搬动地基。孩子先找到低音区的键，再邀请左手走一条已经熟悉的路，最后把这条路放到低音谱表上。

### 第五章：会唱歌的大家园

咚咚从地下生态层发出信号，星芽在可呼吸花园的中继台回答，远处的月亮小家显示成地图上的信号灯。两个朋友先一个说、一个答，再轮流把临时路线升级成永久家园桥。低音谱表和高音谱表变成上下两张相连的地图。孩子可以用“接力版”完成故事；准备好的孩子还可以尝试两只手一起落地。两条路线都会打开同一个花园。

## 两个主角是谁

### 星芽

- 它是原创外星物种“星芽龙”，身体参考敏捷的小型鸟脚类幼龙，不冒充霸王龙、腕龙或任何现实物种的科学复原。
- 身形较高、尾巴向上，动作轻快。
- 头顶只有三颗柔软青绿色头芽，尾巴负责保持跳跃平衡。
- 喜欢先侧耳听，再往前跳。
- 它不是老师，不长篇解释；它用动作告诉孩子下一步看哪里。
- 孩子点错时，它只轻轻踉跄，再指一指正确的键位方向。

### 星芽为什么有时穿宇航服、有时不穿

- 月球表面、小家尚未密封时和星星桥开放太空中：穿完整气密服，包括透明头盔、连体软服、手套、靴子、生命维持背包和气密尾套；不能只戴一个头盔。
- 已经增压的飞船或月亮小家内部具备开盔条件，但第一、二章正式游戏画面仍保持完整密封，避免为了短暂屋内停留反复开盔、收纳和重新密封；第一次明确展示开盔发生在第三章空气检测通过后。
- 第三至第五章：花园经过检测可以呼吸，星芽脱去外层，只保留探索背带和星星背包，方便孩子看清侧耳、说话和跳跃表情。
- 穿脱过程自动发生，只负责讲环境故事，不让孩子寻找按钮，也不参与音乐答案提示。

### 咚咚

- 圆扇形颈盾、三只短角、宽脚掌，重心比星芽低。
- 它慢一点，但不是笨；稳稳托住桥是它的重要能力。
- 它通过跺脚、推石头、托桥和脚印表达低音。
- 颜色和“石头很重”只能帮助营造感受，不能替孩子给出答案。

## 孩子每一关都经历什么

每一关都遵循同一条简单规律：

1. 画面里先出现一个看得懂的小问题。
2. 恐龙用一句短话或一个动作邀请孩子帮忙。
3. 孩子听、看谱或看键盘位置，然后按一个或几个音。
4. 答对后，世界立即变化。
5. 答错后，游戏说出孩子刚按的音，再给键位或谱位线索，不扣星、不弹失败框。
6. 完成后自动进入下一段故事或自然停下，不要求孩子寻找“下一关”按钮。

## 不是连续闯 39 关，而是一小段一小段地玩

4-6 岁孩子不应该从 M01 一直被推到 S01。一次正常游戏只安排大约 3-5 分钟：先做两三个很小的动作，再把刚见过的内容找一次，看到一个完整的故事变化，然后自然休息。

所谓“两三个动作”不一定是两三个关卡。例如 M01 里“听星芽说 Do、找到两个黑键左边、让地板落下”已经是一段完整短课。孩子需要较多帮助时，当天不再追加小考；游戏让地板稳稳落下，星芽坐下来休息，下次再从一个很短的回忆动作开始。

每段短课都分成四步：

1. **摸一摸**：答案比较明显，让孩子先敢按、敢听、敢试。
2. **学一学**：把声音、唱名、字母名、键位或谱位中的一个新联系说清楚。
3. **试试看**：把大亮光收起来，只找一次刚学过的内容。
4. **看世界变化**：地板落下、花朵打开、桥长出来或恐龙到达休息点。

从孩子的感受看，一次短课应该像下面这样走，而不是像一张题单：

| 孩子的感受 | 画面和声音要做什么 | 这一刻真正教什么 | 这一刻不能急着判断什么 |
| --- | --- | --- | --- |
| `咦，那里怎么了？` | 先出现一个睡着、断开、没装好或需要回应的具体东西 | 明白为什么现在要弹琴 | 不评分，不先讲规则长文 |
| `我敢试一下` | 星芽示范一次，琴键、黑键组、谱位或声音给足帮助 | 对新音或新联系留下第一印象 | 不判断独立掌握，不催速度 |
| `原来我的声音有用` | 第一次正确输入立刻让灯、零件、叶子或角色动起来 | 建立“音乐动作会改变世界”的因果 | 不弹收藏页打断动作 |
| `我会一点了` | 用 2-4 个很短的动作把同一个联系再用几次 | 在唱名、字母、键位、谱位和声音中连起本关规定的两项 | 不同时再教第二个新知识点 |
| `这次让我自己找` | 只减少一个强提示，把它藏成最后一块或最后一跳 | 看孩子本次能否少提示找回 | 不把一次成功说成永远记住 |
| `这是我修好的` | 建筑、桥、植物或朋友发生永久变化 | 巩固刚才的因果和完成感 | 不再追加一串测试 |
| `我可以停，也可以以后再来` | 角色坐下、侧耳听或望向下一站，自动播放停止 | 给注意力和记忆留下停顿 | 不要求找“关闭”或“下一关”按钮 |

孩子状态不同，短课也要跟着变化：

- **很顺利**：少放一次重复示范，最多做一个少提示小挑战，不临时加快或加新音。
- **有点犹豫**：只补一个必要线索，给孩子时间；用了强提示就诚实记为“在帮助下玩过”。
- **连续按错**：比较刚按的音和目标音，缩小选择，必要时让角色和孩子一起完成；不扣星，也不拆掉已经建好的东西。
- **开始乱按或只追特效**：收起无关粒子和装饰，只保留当前声音、当前物件和可按区域。
- **明显累了**：做完眼前最小的一步就休息，剩余检查下次再做，不要求重头来。
- **还想继续**：先让孩子看到休息终点，再由孩子主动进入下一小段；游戏不能自己不停播下去。

判断是否“好玩”，不是看彩带和徽章多不多，而是看孩子能否清楚感觉到：**这是我刚才弹的音让它发生了变化。** 每 1-2 个音乐动作要有一次小进展，每个短课要留下一个永久结果，每章要发生一次地点、关系或角色能力的大变化。

下面这些现象说明节奏仍然枯燥，需要返工：连续三次按键世界都没变化；连续三小段都只是追亮键；答对答错看起来差不多；徽章和语音不断打断钢琴；完成后马上又自动出题；或者一次同时换新音、新谱、新手和新节奏。

界面里的名字有固定载体：琴键、任务/目标卡、当前零件、谱垫与谱旁提示、路线节点、定位提示、答对答错反馈、特效、结果、地图和花园物件都只显示 `C/D/E/F/G` 字母音名；只有星芽或咚咚的小恐龙对话框可以显示 `Do/Re/Mi/Fa/Sol` 唱名。答对或修复时通过两个载体重新连接，例如普通界面写“`C · 两个黑键左边`”，星芽同时说“这是 `Do`，你来弹 `C`”。不能再把 `Do/C` 做成普通徽章、小字副标或飞行粒子。

本教案正文为了让家长看懂，仍会用 `Do/C` 描述两种名称的对应关系；这只是成人脚本记号，不等于运行界面要照字显示。家长端和不泄露目标的无障碍说明可以保留双身份。

动作句也要分清谁在做什么：可以说“星芽唱 Do，你来弹 C”，不能只写“唱 Do”让孩子误以为要开口，也不能写“唱 Re/D”把唱名和字母名混成一个要唱的词。

这里有三个不同的“大人用词”：

- **玩过**：孩子在提示下完成过。
- **本次稳定**：这一回减少提示后还能完成。
- **隔一次还记得**：必须是另一次游戏，换到另一个本地日期并至少隔 8 小时，再次减少提示仍能找到。这个时间只是当前产品的诚实记录规则，正式发布前还要让钢琴老师复核。

故事可以在“玩过”以后继续，不用把孩子卡在原地；但家长端不能把刚学完马上做对写成“已经长期掌握”。

### 建议短课顺序

| 章节 | 建议分段 | 每段结束时孩子看到什么 |
| --- | --- | --- |
| 第一章 | `M01`；`M02`；`M03`；`M04-M05`；`M06`；`M07`；`M08`；`FG01-FG02`；`FG03`；`FG04` | 小家每次只长出一块真正有用的部件，最后展开桥前地图 |
| 第二章 | `S01-mini`；完整 S01 引导版；另一次 S01 减提示版 | 先到小休息星，再到对面星球，最后把桥变成自己会走的路 |
| 第三章 | `LS01-LS02`；`LS03`；`LS04`；`LS05`；`LS06`；`LS07`；`LS08` | 叶子、花朵和藤蔓依次醒来，最后低音回声钻入地下 |
| 第四章 | `LP01-LP02`；`LP03`；`LP04`；`LP05`；`LP06`；`LP07`；`LP08`；`LP09`；`LP10` 引导过桥；后来的 `LP10` 信号检查 | 洞门、地基、脚印、谱线地图和低音桥逐步完成；过桥后即可继续故事，检查不重走已完成桥 |
| 第五章 | `TH01-TH02`；`TH03`；`TH04`；`TH05` 桥墩；`TH05` 星灯；`TH05` 接力；`TH08` 接力结局 | 两个家先互相回答，再分多次建桥和练接力，最后打开同一个大家园 |

第三章特意把 `LS03` 和 `LS04` 分开。`LS03` 仍是“普通界面看见 E、听星芽说 Mi，再模仿同一个音”，第三片叶亮起后就是自然休息点；下一次开始 `LS04`，才第一次把音名字母和强亮键藏起来，让孩子在已经练过的 C/D 小音组里听后找键。这样不会在同一小段里同时更换玩法规则和答案呈现方式。

`TH06-TH07` 是准备好的孩子才会看到的额外邀请，不属于必须完成的主线。它们做不成也不会失去结局、奖励或角色认可。

短课之间不是生硬切断。段内答对后自动播放动作并进入下一小步；到休息点时，星芽或咚咚坐下、侧耳听或望向下一颗星，画面回到可继续探索的世界。孩子不需要关闭结果框，也不需要寻找“下一关”按钮。

## 第一章逐关脚本：月亮小家

### M01 第一块月亮地板

**开场画面**

星芽的小飞船刚落地。舱门打开前，它把透明头盔扣好，完整气密服也包住手脚和尾巴。舱门外只有一个圆坑，第一块地板悬在吊机上，没有声音就不会下降。

**星芽说**

“先找 Do。它住在两个黑键左边。”

**孩子做什么**

在真实黑白键布局上按中央 C。第一轮以大字 C 和两个黑键的小地图为主，星芽口语说“Do”。

**答对时**

地板从吊机上落进圆坑，星芽先踩一脚确认稳了，再站到上面向孩子挥手。

**答错时**

游戏先说出刚按的音。例如：“这是 Re。Do 在两个黑键左边。”星芽指向两个黑键，不重复整段说明。

**真正学到什么**

Do 的唱名、字母 C 和“两个黑键左边”的位置第一次连在一起。这一关只算认识过，不算已经掌握。

### M02 三颗小灯醒醒

**开场画面**

小家墙上有三颗从左到右排列的睡眠灯，灯罩分别位于两个黑键旁的三个白键位置。

**星芽说**

“Do、Re、Mi，从左到右叫醒它们。”

**孩子做什么**

依次按中央 Do、Re、Mi。每次只突出当前灯，未来两步保持安静。

**答对时**

三盏灯依次睁开“小眼睛”，光线从左向右流过墙面。

**答错时**

按到的灯轻轻摇一下，目标灯再呼吸一次。游戏说出两个音的名字，并显示“左边、中间、右边”的黑键小地图。

**真正学到什么**

Do、Re、Mi 在两个黑键周围的相对位置，而不是三种颜色的对应关系。

### M03 会唱小车轮

**开场画面**

月亮小车缺一只轮子。轮子藏在箱子里，先唱出 Re，再唱出一声 Do 的回声。

**星芽说**

“轮子先唱一声，你来弹同一个音。”

**孩子做什么**

先听 Re 并按相同琴键，再听 Do 并回应。目标音播放前，琴键和音名不直接发亮。

**答对时**

第一声让轮子从箱子里探头，第二声让它滚到小车上并自动扣紧。

**答错时**

轮子停下，游戏先说出刚按的音，再重放目标音并显示目标的黑键位置。揭示后的句子必须分清角色和两套名称，例如“轮子唱 Re，你来弹 D”或“轮子唱 Do，你来弹 C”；不能写成“唱 Re/D”。孩子可以重复听，不扣分。

**真正学到什么**

第一次尝试“听到声音，再去键盘找”，为第三章埋下种子。这不是麦克风关，也不是绝对音感考试。

第一次把 Re、Do 两声都找对只记为“听音玩过”。另一次短回忆仍能在答案不提前出现、没有强亮键的情况下把两声都找对，家长端才可写“听音稳定”；这仍不是 `retained`，隔日保持必须以后再单独验证。

### M04 咔哒小桥

**开场画面**

小家门口到小车之间缺三块桥板。三个卡槽从左到右空着。

**星芽说**

“Do、Re、Mi，桥板会跟着琴键往右走。”

**孩子做什么**

依次按 Do、Re、Mi，同时看见琴键位置和桥板都从左向右移动。

**答对时**

每个音让一块桥板“咔哒”落下，星芽最后走过桥板去摸小车。

**答错时**

桥板不会落错位置。星芽退回上一个卡槽，用尾巴指出移动方向。

**真正学到什么**

音往上走时，琴键也向右走。孩子开始把旋律方向和键盘方向联系起来。

### M05 火箭倒数灯

**开场画面**

屋旁的小火箭有三盏倒数灯，最上面的灯先亮，必须一路回到下面才能安全启动。

**星芽说**

“Mi、Re、Do，从高处一盏一盏回下来。”

**孩子做什么**

依次按 Mi、Re、Do。画面中的光点向下，键盘上的位置向左。

**答对时**

三盏灯向下完成倒数，火箭只喷出一小团庆祝蒸汽，不真的飞走。

**答错时**

光点停在当前高度。星芽做一个向下的手势，游戏只提示下一音。

**真正学到什么**

下降旋律对应键盘向左，和上一关的上行形成清楚对比。

### M06 大跳墙

**开场画面**

小家的前墙折叠在地上。底部锁扣在 Do，墙顶拉环在较远的 Sol，最后还要回 Do 扣住底座。

**星芽说**

“踩 Do 起跳，跳到 Sol 拉起墙顶，再回 Do 扣好。”

**孩子做什么**

依次按 Do、Sol、Do。第一轮清楚显示 Sol 在三个黑键第一和第二个之间，孩子不需要张开手跨住五个键。

**答对时**

第一个 Do 解开底锁，Sol 把墙板拉起来，最后一个 Do 让底座“咔哒”固定。三个音有三个不同结果，不是抽象地“立墙”。

**答错时**

墙板只停在原角度。星芽从 Do 的位置画出一条弧线，指向三黑键旁的 Sol。

**真正学到什么**

体验 Do 到 Sol 的远距离跳进，并第一次认真看 Sol 的键位。这只是强提示预览，不算 Sol 稳定掌握。

### M07 星星记忆串

**开场画面**

五颗星灯散在地上。星芽先用尾巴轻点出一条 Do、Re、Mi、Re、Do 的小路，然后灯光熄暗。

**星芽说**

“刚才的星星路，你还记得吗？”

**孩子做什么**

第一遍在星芽示范、当前星位和必要键位提示下依次弹 C、D、E、D、C；星芽口语用 Do、Re、Mi、Re、Do 带路。错误后只恢复当前一步提示，不重新显示整串答案。

**答对时**

五颗星依次飞到门檐，组成一条会呼吸的灯串。

如果第一遍没有反复修复、强提示、共同完成或长时间等待，已经挂好的星星不会掉回地面。灯串转入“记住刚才路线”的状态，孩子少提示再弹 C、D、E、D、C；每个音只在原位留下一个记忆光点。第二遍的故事作用是让星串记住顺序，不是把同一批星重新挂一次。第一遍吃力时，星串保持挂好并直接进入休息，少提示检查留到以后。

**答错时**

已经挂好的星不掉下来。当前空位闪一下，星芽只示范下一音。

**真正学到什么**

第一次从“跟着按”进入短序列记忆，并检查 Do、Re、Mi 键位是否开始稳定。

### M08 合上月亮屋顶

**开场画面**

屋顶分成五块弧形板，从左下到右上悬着。最后两块靠近三个黑键，是之前较少接触的 Fa 和 Sol。

**星芽说**

“从 Do 一步走到 Sol，屋顶会沿着声音合起来。”

**孩子做什么**

依次按 C、D、E、F、G。星芽可以依次说 Do、Re、Mi、Fa、Sol；F 和 G 获得黑键定位帮助，但不只靠不同颜色。

**答对时**

五块屋顶沿上行方向逐块合拢，最后露出一扇密封透明天窗。星芽仍穿完整气密服，从天窗看见远处的新星球。

如果孩子第一遍完成得比较轻松，屋顶合拢后不再把五块板拆开重装。画面转成五个气密检查灯，普通路线用少一点提示再显示 C-D-E-F-G，星芽仍可依次说 Do-Re-Mi-Fa-Sol；每个音点亮一个密封点，最后小屋出现安全压力光。压力光证明前哨已经密封，不要求角色摘头盔。这样第二遍是在“检查新屋顶”，不是原样做第二套练习。若第一遍已经反复修复、等待很久或由星芽共同完成，就直接在合拢屋顶处休息，把气密检查留到以后。

**答错时**

当前屋顶板在正确卡槽前停住。若 E/F 或 F/G 混淆，普通界面放大两个黑键组之间的边界；星芽可在对话框里补充对应唱名。

**真正学到什么**

把五个连续音第一次走完整，并为 Fa、Sol 的专门补课和五线谱桥作准备。只有符合少提示门槛的气密检查才可能形成本次 stable；一次安装完成不等于 F/G 已稳定。

### FG01 Fa 落脚垫

**开场画面**

天窗外出现星桥入口，但第一块垫子缺失。空位紧靠三个黑键左边。

**星芽说**

“Fa 在三个黑键左边。请它送来第一块垫子。”

**孩子做什么**

单独找到 Fa，并与旁边的 Mi 做一次边界比较。

**答对时**

第一块落脚垫从天窗外飞来，锁在星桥入口。

**答错时**

如果按 Mi，游戏明确显示“两个黑键右边”和“三个黑键左边”是相邻的两个家。

**真正学到什么**

Fa 的独立键位，不再只是五音上行中的第四步。

### FG02 Sol 星门

**开场画面**

落脚垫前有一道半开的星门，门锁位于三个黑键之间的第二个白键。

**星芽说**

“Fa 后面还有 Sol。它在三个黑键第一和第二个之间。”

**孩子做什么**

单独找到 Sol，并与 Fa 做一次左右位置比较。

**答对时**

星门打开，远处星球的光第一次完整照进月亮小家。

**答错时**

门不关闭，只显示三个黑键和旁边两个白键的简图。

**真正学到什么**

Sol 的独立键位，以及 Fa/Sol 在三黑键组旁的先后关系。

### FG03 三颗近邻星

**开场画面**

Mi、Fa、Sol 三颗星挤在一起，找不到从近到远的顺序。

**星芽说**

“先分清 Mi 和 Fa 的边界，再找到 Sol。”

**孩子做什么**

在较少亮键的情况下完成 Mi、Fa、Sol，并穿插短随机比较。

**答对时**

三颗星排成一阶小梯子，正好指向谱桥入口。

**答错时**

只显示发生混淆的两颗星和对应黑键组，不把第三个答案一起给出。

**真正学到什么**

修复最常见的 E/F、F/G 邻音混淆，为正式读谱减少挫败。

### FG04 桥前小地图

**开场画面**

星门后出现一张只有两处亮点的小地图：F 在第一间，G 在第二线。完整星桥仍在远处。

**星芽说**

“Fa 住在第一间，Sol 站在第二线。先把地图和琴键对上。”

**孩子做什么**

分别看见 Fa、Sol 的谱位，再去键盘找对应音。第一轮保留标签，第二轮减少亮键。

**答对时**

两处谱位变成真正的桥垫，月亮小家的天窗完全打开。

**答错时**

游戏同时指出目标谱位和黑键位置，但不把整座桥都照亮。

**真正学到什么**

第一次把 Fa/Sol 的音名、键位和五线谱位置连接起来，避免第二章像突然换了一种游戏。

## 第二章逐关脚本：星星桥

### S01 星星桥第一跳

这一章当前不是很多小关，而是一座在三次短课中重复使用的主桥：`S01-mini` 只观察前三跳，`S01 guided` 带路走完全桥，后来的 `S01 check` 少提示确认路线。三次都发生在同一桥景里，但每次到安全停点后都回地图休息，不在一个 session 里连续推完，也不弹出“下一关”窗口。

**开场画面**

左边能看到刚完成的月亮小家，右边是会听的小种子星球。星芽一直保持完整密封探索服，中间只有一到两个小节长的五线谱桥，五条线粗、间距清楚，六个落脚垫准确放在谱位上。

**星芽说**

“谱线上的垫子告诉我跳哪里。你在琴键上找到同一个音。”

**孩子做什么**

依次完成 Do、Re、Mi、Fa、Sol、Mi：

- Do：下加一线；
- Re：五线谱下方；
- Mi：第一线；
- Fa：第一间；
- Sol：第二线；
- Mi：回到第一线。

**第一段：前三跳观察（S01-mini）**

只走 C、D、E 三个落脚垫；星芽对话框依次说 Do、Re、Mi。当前垫只显示字母名 C/D/E 和必要的黑键定位；唱名不作为谱垫小字。未来垫保持可见但不抢注意。孩子按对一个音，星芽才真正起跳、腾空并落到对应谱位。到第三跳的小休息星就结束，本段只用于观察孩子是否理解规则，不写完整 S01 stable 或 retained。

**第二段：带路过桥（S01 guided）**

另一次短课从桥头出发，按 C、D、E、F、G、E 走完整路线；星芽对话框可依次说 Do、Re、Mi、Fa、Sol、Mi。当前垫以字母名 C/D/E/F/G 和黑键定位为主；孩子走到右侧星球后在星门前休息，不自动开始少提示检查。

**第三段：少提示确认路线（S01 check）**

孩子在后来的独立短课里少提示重走已经见过的路线，目标键不再持续发光。如果 F 或 G 连错两次，星芽不宣布失败，而是回到 FG01-FG03 的小练习；故事仍可在共同完成后到达花园入口，但本次不写 stable 或 retained。

**答对时**

星芽从当前谱垫跳到下一垫，已完成垫变成稳定星光。少提示路线结束后，桥留下永久星光，地图把当前地点停在右侧星球的花园入口；角色不自动走进花园，也不无手势启动第三章。

**答错时**

星芽在原垫轻轻打滑但不掉下去。游戏说出刚按的音，再提示目标谱位和黑键位置。例如：“这是 Re。要 Do：下加一线、两个黑键左边。”

**真正学到什么**

五线谱位置、音名和键盘位置是一条连续路径。孩子不是按发光按钮让恐龙跳，而是读出恐龙下一步要落在哪里。

## 第三章逐关脚本：会听的小种子

这一章不考“从安静中凭空说出一个音是什么”，也不宣称训练绝对音感。孩子先看见并模仿单音，再在刚练过的两个或三个音中听后找键，最后记住两个连续声音。

前面三关只是教会玩法并留下“玩过”的记录，不会因为没有 stable 而被系统反复塞进开场复习。后面听辨遇到困难时，星芽可以带孩子回来看一次 C、D、E 的键位家；这叫补教，不是假装孩子已经完成隔日保持测试。

小恐龙跳结束后，地图把星芽带到花园入口休息，不重新指回第一章。孩子下一次点花园入口时，空气检测、开盔和收纳自动完成，然后开始第一颗种子；这里没有“下一关”弹窗。若第一颗种子出现反复修复、强提示、共同完成、长时间等待或明显疲劳，就在第一片叶保持打开的位置先休息；下一次只接着做 Re，不强行继续新音，也不要求把第一片叶重新打开。

### LS01 第一颗会唱种子

**开场画面**

星芽到达花园入口时，星星背包先播放一段很短的空气检测动作。安全信号出现后，头盔向后打开、外层压力服自动收好；星芽用本体加探索背带走进花园。一颗种子闭着眼，旁边以大字 `C` 和“两个黑键左边”显示键位家；唱名 `Do` 由星芽说出来，不再另放一张同等醒目的身份卡。

**星芽说**

“种子先唱 Do，你来弹 C 回答。”

**孩子做什么**

先看见大字 `C` 和两个黑键左边的位置，听见中央 Do，再按这个 `C` 键回声。

**答对时**

种子打开第一片叶，叶片和钢琴音同时停止，不用额外音效盖住 Do。

**答错时**

种子重新唱 Do，游戏交替播放目标音和孩子刚按的音，让孩子比较后再试。

**真正学到什么**

建立最简单的“角色唱唱名、孩子弹对应字母键”的听后模仿规则，不做稳定掌握判断。

### LS02 Re 的小芽伸懒腰

**开场画面**

第二颗种子的茎卷成一团，卷心位于两个黑键中间的白键方向；可见教学以大字 `D` 为主名，星芽口语称它 `Re`。

**星芽说**

“小芽先唱 Re，你来弹 D，让它伸直。”

**孩子做什么**

先看见大字 `D` 和两个黑键中间的位置，听见 Re，再在键盘上按这个 `D` 键回声。

**答对时**

卷曲的茎慢慢伸开，指向两个黑键中间。

**答错时**

茎不缩回。星芽指出 Do、Re、Mi 的中间位置并重放 Re。

**真正学到什么**

把已经认识的 Re 键位加入同样的听后模仿规则。

### LS03 Mi 点亮第三片叶

**开场画面**

第三片叶躲在阴影里，叶尖靠近两个黑键右边的白键；可见教学以大字 `E` 为主名，星芽口语称它 `Mi`。

**星芽说**

“叶片先唱 Mi，你来弹 E 回声。”

**孩子做什么**

第一轮看见大字 `E`、键位家并听见 Mi；第二次直接听后找同一个 `E` 键，目标键不持续发光。

**答对时**

叶片接住一颗小星光，三片叶组成完整小芽。

**答错时**

游戏说出刚按的音，再显示 Mi 在两个黑键右边。

**真正学到什么**

完成 Do、Re、Mi 三个单音的可见模仿，为之后隐藏目标作准备。

### LS04 Do 和 Re 找朋友

**开场画面**

两颗种子和两朵花面对错了方向。中央有一颗没有音名和颜色答案的回声种核。回合开始前，Do 会作为参照音唱一次；正式呼叫时由回声种核播放不带“Do/Re”唱名的钢琴音，两颗种子都保持不动。

**星芽说**

“先记住 Do。接下来听见 Do 或 Re，就按同一个键。”

**孩子做什么**

完成四次平衡的 Do/Re 短呼叫，Do 和 Re 各出现两次，顺序随 session 变化。每次目标音出现前不显示名字和强亮键，孩子可以点重听。

**答对时**

对应种子短暂转向自己的花，确认后两颗种子都回到相同等待姿势；中性叶片只记录“已经完成几次”，不记录刚才是 Do 还是 Re。四次都走完后，两边才永久转向并握住叶子。

**答错时**

游戏先播放孩子按出的音，再播放目标音，最后才显示两个黑键的小地图。

**真正学到什么**

在刚练过的两个音里听后找键。三次或以上答对才算这组开始稳定。

### LS05 花粉铃叫醒三朵花

**开场画面**

三朵分别认识 C、D、E 的花固定排成一个小弧形，围着中央花粉铃等待；星芽口语把它们称作 Do、Re、Mi。正式目标只由花粉铃播放不带名字的钢琴音，三朵花在孩子回答前都不移动、不张合、不摇摆、不单独发光；每组开始前，普通界面显示一次 C 定锚，星芽对话框可说 Do。

**星芽说**

“花粉铃会唱三朵花认识的声音。先听，再找同一个键，不用猜颜色。”

**一轮实际怎样演**

| 时刻 | 孩子看到什么 | 星芽怎样说 | 教学含义 |
| --- | --- | --- | --- |
| C 定锚 | 中央花粉铃和固定弧形的三朵同态花；普通界面只显示大字 `C` 与两黑键左边 | “先听 `Do`，你在琴键上找 `C`。” | 把口语唱名重新接到字母音名和键位；这一声不计题 |
| 正式响铃 | 花粉铃做完全相同的中性声波；三朵花都不动；普通界面不出现目标字母 | “花粉铃响啦，听完再找同一个键。” | 目标只能从钢琴声音获得 |
| 等待作答 | 真实黑白键保持正常字母；只有中性重听图标和五格花粉环 | 不重复目标名，也不说哪朵花 | 孩子自己把声音对应到键位 |
| 首答正确 | 孩子按的键先清楚发声，普通界面答后显示例如 `E · 两黑键右边`；对应花短开后复位 | “这是 `Mi`，你找到了 `E`。” | 在答案已经产生后连接唱名、音名和键位 |
| 第一次答错 | 普通界面只显示“刚按 `D`”；先听孩子按出的 D，再听目标，花不枯萎 | “先听你按的 `Re`，再听花粉铃。” | 比较两个真实声音，不把错误变成惩罚 |
| 同一题再次混淆 | 普通界面只出现同权的两个字母和黑键位置，例如 `D / E`；第三个音退出修复画面 | “`Re` 和 `Mi` 一起来听一听。” | 缩小混淆对，但仍不靠颜色或大小给答案 |
| 强帮助 | 正确字母、键位家和短键脉冲出现；本轮已失去 stable 资格 | “看 `E` 在两个黑键右边，我们一起找。” | 让孩子完成有意义的最后动作，证据保持诚实 |
| 听力辅助 | 只在听力辅助已开启、声音持续不可用或 strong-help 后出现字母+键位模型 | “声音今天休息，我们看着找。” | 可以完成故事，但不冒充隐藏听辨正确 |
| 五步完成 | 三朵花在原位置一起开放，花粉环变成完整小圈，随后自然回地图 | “三朵花都醒啦，今天先在花园歇一会儿。” | 给明确成就感并停止自动出题 |

**孩子做什么**

完成五次 C4、D4、E4 小音组匹配。重听始终可以使用；孩子主动重听超过一次仍会完成花园故事，但本轮不写 stable。

**答对时**

相应位置的花短暂开放，确认后与另外两朵一起回到相同等待姿势；跨呼叫只保留不带音符身份的花粉点。五次都走完后，三朵花才一起开放成小弧线。

**答错时**

花不枯萎。系统回到发生混淆的两音比较，例如普通界面只比较 D/E，星芽对话框可以说 Re/Mi；第三朵花不参与这次修复，也不闪出答案。

**孩子累了或需要看着完成时**

已经得到的中性花粉点留在原处。下一次从地图回来只继续剩下的花粉步，不要求重做；如果使用字母和键位的可见帮助，三朵花仍能一起开放，但家长端只记录“在帮助下完成故事”，不把它说成听音已经稳定。

**真正学到什么**

把听后找键从两个音扩到三个已知音。要记录“本次稳定”，不仅要五次中至少答对四次，还要 Do/C、Re/D、Mi/E 三个音各有至少一次没有强提示的正确；不能因为只错了那个仅出现一次的音，仍把整个三音集合写成稳定。家长端只能写“能在小音组里听后找键”。

### LS06 远远的回声藤

**开场画面**

两块花园石离得很远，普通标记一端是 C，另一端是 G。中间的回声石负责播放不带名字的目标钢琴音，近端和远端在孩子回答前都不冒芽、不发光，藤蔓只能听懂这两个差别较大的声音。

**星芽说**

“Do 在近处，Sol 在远处。先听，再让藤蔓长过去。”

**孩子做什么**

完成四次 C/G 比较。第一轮可以看到两个键位家，星芽可说 Do/Sol；检查轮只保留声音和正常键盘位置。

**答对时**

孩子回答后，C 或 G 对应的一端可以短暂回应，但下一次呼叫前两端必须恢复同态；永久留下的藤结从中央对称生长，不记录刚才出现的是哪一个音。四次都走完后，藤蔓才形成完整植物小拱门。

**答错时**

藤蔓停下，星芽重放两个音并在键盘上画出两者距离，但不把距离动画当答案。

**真正学到什么**

先听清大距离音高差，为下一关较难的相邻音比较做准备。

### LS07 挨着睡的 Mi 和 Fa

**开场画面**

Mi 和 Fa 两朵花挤在两个黑键组与三个黑键组的交界，叶子缠在一起。中央露珠播放不带唱名的目标钢琴音，两朵花在孩子回答前保持相同姿势。

**星芽说**

“它们住得很近。听清是 Mi，还是旁边的 Fa。”

**孩子做什么**

完成四次 Mi/Fa 比较。错误后可以分别试听两个候选键，再听目标。

**答对时**

刚才对应的花可以短暂亮一下，随后两朵恢复相同等待姿势；跨呼叫只保留中性的解结进度。四次都走完后，两株花的茎才永久分开并各自站稳。

**答错时**

只显示“两个黑键右边”和“三个黑键左边”的边界，不出现整排彩色提示。

**真正学到什么**

听辨和键位上都最容易混淆的 E/F 相邻关系。至少三次答对才算这组开始稳定。

### LS08 根须记两声

**开场画面**

花园里的根须形成两个空的声音位置。两个不带唱名的钢琴短音由中央中性声源播放；星芽只做每次完全相同的侧耳和“听两声”动作，不用嘴型、头芽、手势或左右位置提示音高。

**星芽说**

“这次听两声。慢慢回给我，不用抢拍子。”

**孩子做什么**

在自由速度下回声四组两音。成人教案里的固定音对是 `C-D`、`E-D`、`C-C`、`D-E`，但正式呼叫期间不显示这些字母或唱名。带路练习可以分开重听两个音；少提示检查只允许整组重听，并且整轮最多由孩子主动重听一次。超过一次仍可完成根须故事，但本次只记为在帮助下玩过，不写稳定。

`C-C` 也必须真的按两次：按住一个 C 不会自动填满两个位置。屏幕琴键要抬手再按，MIDI 要松键再按，真钢琴声音要在两次起音之间短暂安静。

**答对时**

根须只在孩子作答后按两个输入位置短暂发光，确认后当前两个声音格清空，留下一个不带音高和顺序信息的中性根结。四组都走完后，所有根须连接到地底；其中至少三组顺序正确才新增本关 stable 证据，故事奖励本身仍可在温和修复或共同完成后获得。

**答错或忘记第二音时**

画面保留第一个正确位置，第二个空位继续呼吸。系统把当前组缩回单音再重新组合，不清空其他花朵。

**章节结尾**

所有任务完成后，种子先唱中央 Do，地底突然回应一个更低的 Do。这个低音没有要求孩子找键，也不算答题。地面出现一圈波纹，远处传来第一声“咚”，第四章自然开始。

**真正学到什么**

第一次记住两个声音的先后顺序。章节末尾只制造“地底还有另一个声音”的好奇，不提前声称孩子认识低音 C3。

## 第四章逐关脚本：咚咚的低音星球

### LP01 地底传来“咚”

**开场画面**

一颗小种子唱出两个 Do。一个像从星空传来，一个让地面出现圆圆的震动。洞口还没有打开。

**星芽说**

“嘘，地底也在唱。听听哪一个 Do 住得更低？”

**孩子做什么**

模型阶段，两个外观、大小和亮度相同的固定声音泡泡分别唱一次中央 Do 和低音 Do，孩子可以重听。正式四次比较由中央声源播放目标，孩子只点与它相同的固定声音泡泡；高、低各出现两次，泡泡不随题目换位置，也没有角色发光或上下动画。LP01 全程只考听觉比较，键盘回应从 LP02 才开始，MIDI 和麦克风输入不用于本关计分。

**答对时**

地面产生一圈柔和波纹，洞穴轮廓亮起来，里面传来一声开心的“咚”。

**答错时**

高处的小星星亮一下。星芽说：“这个 Do 住得高。再听听地底的 Do。”随后只重放声音，不马上照亮答案键。

**真正学到什么**

同样叫 Do 的声音可以有高有低。此时不讲左手，也不讲低音谱号。

### LP02 低音 Do 的家

**开场画面**

洞门上有两个 Do 形状的门铃，一个在星芽旁，一个在更低的键盘区域。门只对地底的 Do 有反应。

**星芽说**

“两个都叫 Do。咚咚的 Do 住在下面那组两个黑键左边。”

**孩子做什么**

孩子在至少两个八度的真实布局中找到低音 C。画面同时保留中央 C，星芽把两者都称作 Do，方便比较“同名、不同家”。

**答对时**

洞门打开一条缝，第一块地基石稳稳落下。

**答错到中央 C 时**

星芽说：“名字对啦！这个是星芽家的 Do。再找下面那个家。”这算接近答案，不算完全错误。

**真正学到什么**

音名相同不代表键位和谱位相同。家长记录为低音 C3；孩子在普通界面辨认低音 C，并听懂咚咚说的“低音 Do”。

### LP03 三块地基石

**开场画面**

三块石头悬在洞里，位置乱了。每一块上只有一个小小的 C、D 或 E 标记，不用颜色直接给答案；咚咚的对话框可以说 Do、Re、Mi。

**咚咚的声音从洞里传来**

“Do、Re、Mi，帮石头从左到右站好。”

**孩子做什么**

在低音区依次按 Do、Re、Mi，找到两个黑键左边、中间和右边的三个白键。

**答对时**

石头逐块卡进地面，形成一条短短的地基路。

**答错时**

游戏先说出刚按的是哪个音，再显示两个黑键的小地图。只提示当前一步，不把后面的答案一起照亮。

**真正学到什么**

低音 Do、Re、Mi 的键盘相对位置。

### LP04 地洞回声

**开场画面**

一团光在洞里往错误方向乱跑。远处只能看见一个圆圆的三角龙剪影。

**剪影说**

“回声要往下走：Mi、Re、Do。”

**孩子做什么**

先听 Mi、Re、Do 的下降，再在低音键盘上按出来。答案键在声音播放前不发光。

**答对时**

光沿着洞壁向下移动，最后照亮咚咚的眼睛和颈盾剪影。

**答错时**

回声停在原地，不倒退。星芽指出刚才的音，并重放目标音。

**真正学到什么**

听见并演奏下降方向，把声音和低音键位连起来。

### LP05 三黑键旁的脚印

**开场画面**

脚印从两个黑键旁边走到三黑键旁边，最后两枚脚印不见了。

**星芽说**

“脚印从 Mi 走到 Fa，再走到 Sol。”

**孩子做什么**

先按 Mi、Fa、Sol，再做几次三者之间的小比较。重点看清 Mi 在两个黑键右边，Fa 在三个黑键左边，Sol 在三个黑键第一和第二个黑键之间。

**答对时**

咚咚从最后一枚脚印后面完整探出头，和孩子第一次正式见面。

**答错时**

脚印停下，画面只放大“两个黑键右边”和“三个黑键左边”的边界，不用整排彩色键提示。

**真正学到什么**

最容易混淆的 Mi/Fa 和 Fa/Sol 键盘位置。

### LP06 咚咚搬大石

**开场画面**

一块拱桥石太大，咚咚推不动。地面出现从低音 Do 跳到低音 Sol 再回 Do 的远距离轨迹。

**咚咚说**

“从 Do 跳到 Sol，再跳回 Do。石头会跟着滚！”

**孩子做什么**

依次按低音 Do、Sol、Do。第一轮保留黑键组定位，之后减少亮键。

**答对时**

石头沿着弧线滚进拱门位置，咚咚拍掉手上的灰，露出得意表情。

**答错时**

石头只轻轻晃一下。咚咚用鼻尖指向三个黑键旁的 Sol 位置。

**真正学到什么**

第一次体验低音区的五度跳进。这是预览，不要求小手张开五个键，也不据此判断已经掌握 Sol。

### LP07 左手小队出发

**开场画面**

五枚脚印排成 Do、Re、Mi、Re、Do。咚咚举起左手图标，自己的左脚也亮了一下。

**咚咚说**

“这条路你已经认识。让左手和我一起走吧。”

**孩子做什么**

用左手走 Do、Re、Mi、Re、Do。孩子也可以先用屏幕琴键完成故事，游戏只记录“提示过左手”，不假装知道孩子实际用了哪只手。

**答对时**

咚咚跺出五枚稳定脚印，每一步都让洞顶掉下一点金色微尘。

**答错或换手时**

不失败。只保留下一只手的图标和当前键位线索。家长端可写“左手练过”，不能写“左手技术已掌握”。

**真正学到什么**

把已经熟悉的低音键位交给左手。孩子画面不出现 5-4-3-4-5 指法数字；指法只在家长提示里出现。

### LP08 地下谱线地图

**开场画面**

五条宽而清楚的发光线从地面升起。刚才的脚印变成谱表上的三个落脚垫。

**咚咚说**

“脚印藏进五条线里啦。先找低音 Do、Re、Mi 的家。”

**孩子做什么**

看到一个低音谱位后，在键盘上找到对应音。顺序是低音 Do 第二间、Re 第三线、Mi 第三间。第一轮同时显示键盘定位，检查轮取消强亮键。

**答对时**

咚咚踩到准确的谱位，谱线像地下轨道一样向前延伸。

**答错时**

咚咚不跳错位置。游戏说出刚按的音，再同时强调目标谱位和黑键组位置。

**真正学到什么**

低音 Do、Re、Mi 的谱位、音名和键位是同一件事的三个线索。

### LP09 低音桥加固

**开场画面**

地下谱桥上半段缺三个支撑点，Mi、Fa、Sol 的谱位被打乱。

**星芽说**

“这次看谱线，帮咚咚把 Mi、Fa、Sol 放回去。”

**孩子做什么**

识别低音 Mi 第三间、Fa 第四线、Sol 第四间，并在正确低音八度按键。

**答对时**

三个支撑点从下到上锁紧，桥面不再晃动。

**答错到正确音名但错误八度时**

游戏说：“Sol 的名字对啦，这次要咚咚家下面的 Sol。”不算低音谱位掌握。

**真正学到什么**

完成低音 C3-G3 的五个谱位，尤其修复 Mi/Fa 和 Fa/Sol 混淆。

### LP10 咚咚的低音星桥

**开场画面**

洞穴与地面之间只差最后一座短桥。谱桥只有一到两个小节长，终点能清楚看到星芽的远方信号。

**咚咚说**

“沿着低音 Do、Re、Mi、Fa、Sol、Mi，走到星芽那边！”

**孩子做什么**

这不是一次连续弹两遍。第一次短课在有提示的桥上弹 C、D、E、F、G、E，让咚咚走到信号塔；桥和角色位置永久保留，故事在引导或共同完成后就可以继续。后来的独立短课再用较少亮键检查同一音序，孩子每弹一个音就点亮桥上已有的一个信号锚，不让咚咚重新过桥。

**答对时**

第一遍中，咚咚逐个落到谱位，抵达终点后用颈盾反射出一束光，远处的星芽立刻回答。后来的检查只让六个信号锚依次稳定发光，已经建好的桥和抵达终点的咚咚不倒退。

**答错时**

咚咚轻轻停步，当前谱垫和键盘定位同时出现；桥不会坍塌，也不清空进度。

**真正学到什么**

把低音、键盘位置、低音谱位和左手体验连成一条完整路径。故事完成只需要走到信号塔；少提示检查才用于判断低音谱桥是否本次稳定。

## 第五章逐关脚本：会唱歌的大家园

第二章的星星桥只够穿气密服的星芽先去探索。第五章的画面发生在可呼吸生态区的安全中继台上：月亮小家作为远端信号和自动施工端点出现，星芽不需要无头盔返回真空月面。咚咚在地下地基站负责低音支撑，星芽在花园中继台用高音信号唤醒远端月亮模块；两位角色都留在生态星球的安全区域。孩子现在修的是能长期承载高音、低音和两个住处的永久双层通道。只要 LP10 在引导或共同完成下把信号送到星芽，主线就可以进入这一章；低音键位或谱位尚未 stable 时保留更多提示，不把故事锁住。

### TH01 两个 Do 说你好

**开场画面**

画面是一张可玩的双端家园地图：左边是咚咚所在的地下地基站和上方花园中继台，右边是远处月亮小家的自动端点。星芽站在花园中继台旁，咚咚守住地基；两人共同操作这张地图，而不是分别站在两个真空星球端点。两个端点都还没有亮。

**咚咚说**

“我先说低音 Do。”

**星芽回答**

“我再说中央 Do！”

**孩子做什么**

按低音 Do，再按中央 Do。画面一次只显示一位角色和一只手的提示。

**答对时**

两盏灯依次亮起，光线跨过一半天空。

**真正学到什么**

两个 Do 同名但不在同一个家；两位角色和高低音先学会轮流。画面可以邀请左右手，但系统不能仅凭音高断定孩子实际用了哪只手。

### TH02 Sol 回声接力

**开场画面**

Do 的光线只能到达半路，远处出现两颗 Sol 星。

**星芽说**

“咚咚的 Sol 先亮，我的 Sol 再回答。”

**孩子做什么**

按低音 Sol、中央上方的 Sol，再按低音 Do、中央 Do。检查轮不直接照亮回答键。

**答对时**

两组光线在天空中接上，桥的两端同时出现第一块材料。

**真正学到什么**

把“同名、不同音区”的理解从 Do 迁移到 Sol。

### TH03 两边轮流修桥

**开场画面**

两边的材料如果一起乱动就会碰撞。咚咚和星芽举起“你一下、我一下”的手势。

**角色只说一句**

“咚咚一下，星芽一下。”

**孩子做什么**

按照慢脉冲轮流弹：左低音 Do、右中央 Do、左低音 Re、右 Re、左低音 Mi、右 Mi。

**答对时**

地图上，生态侧地基和远端月亮自动模块轮流长出一段桥；每个轮次只移动一块材料，两位角色始终留在安全控制区。

**答错音或轮次时**

画面暂停，只留下下一位角色和它的手势，不弹出长文字。

**真正学到什么**

左右交替与等待轮次。系统记录的是“提示哪只手”和按键时间，不能只凭音高断定真实手型。

### TH04 中央 C 会合点

**开场画面**

高音谱表和低音谱表像两张分开的地图。普通地图把低音 C 放在下面，把中央 C 做成两张地图之间的一盏会合灯；星芽在对话框里把它们都称作 Do。

**星芽说**

“低音 Do 从下面出发，中央 Do 在这里等我们。”

**孩子做什么**

先找到低音谱表第二间的 C3，再找到已经认识的高音谱表下加一线 C4。系统只把 C4 称为中央 C。

**答对时**

大括号合拢，两张谱表成为一张大谱表，会合灯只出现一次。

**真正学到什么**

低音谱表和高音谱表能够连接；C3 不是中央 C，C4 才是这次的会合点。

### TH05 一边托住，一边点灯

**开场画面**

咚咚要放两块桥墩，星芽要点亮八颗星。孩子先分别练，再用接力方式完成。

**咚咚说**

“我先放一块，你再点四颗。”

**孩子做什么**

这一任务至少分成三个可续接的短 session，不要求一次做完：

1. 先弹咚咚的低音 C、低音 G，放下两块永久桥墩。
2. 再练星芽的两个四音灯组：C-D-E-D 和 E-D-C-C；第一组结束就有自然停点，状态好才继续第二组。
3. 后来的短课才做完整接力：低音 C，星芽四音；低音 G，星芽四音。已经放好的桥墩和点亮的灯不清空。

**答对时**

每个阶段都留下永久结果：两块桥墩先落下，两组星灯随后保存，最后接力让主桥真正接通。孩子在任何自然停点离开，下次都从未完成阶段继续。

**真正学到什么**

两只手可以有不同工作。4-6 岁孩子到这里已经可以进入最终花园，不需要通过同时弹奏考试。

### TH06 第一次一起落地（可选奖励路线）

**开场画面**

主桥已经能走，旁边还有一座所有孩子都会点亮的练习拱门。拱门上有两个接近同时落地的圆点。

**咚咚说**

“想不想和我一起落地？”

**孩子做什么**

尝试低音 Do 与中央 Do 一起按，再尝试两边的 Sol，最后回到两个 Do。只有触屏多点或 MIDI 能记录双音；麦克风路线仍然按顺序玩。

**答对时**

两只恐龙一起落地，练习拱门发出短暂的双层光圈。这个光圈是动作反馈，不是独占收藏。

**没能同时按时**

没有失败。角色笑着改成一前一后落地，同一座练习拱门照样亮起，然后系统自动回到接力路线。两种结果留下相同的永久场景。

**真正学到什么**

体验“接近同时”的双音起点。友好动画可以很宽松，家长数据使用更严格的时间差，但仍不能证明手型正确。

### TH07 两小节小合奏（可选奖励路线）

**开场画面**

孩子已经听过接力版。现在同一首曲子分成上下两条角色轨道，没有新旋律，也没有突然增加难度。

**两小节曲子**

| 数拍 | 1 | 2 | 3 | 4 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 星芽 | Do | Re | Mi | Re | Mi | Re | Do | Do |
| 咚咚 | 低音 Do，尽量保持四拍 |  |  |  | 低音 Sol，尽量保持四拍 |  |  |  |

**孩子做什么**

速度约为每分钟 52 拍，但节拍不用于惩罚。TH05 已经分别教过两个声部；这里不再要求先把两只手完整重练一遍。第一次短课只尝试第一小节，第二次短课只尝试第二小节；每小节第一拍是唯一需要尝试一起落地的位置。两小节都见过以后，TH08 才邀请完整演出。低音提早松开只会得到温和提醒，不会失败，也不用踏板。

**答对时**

低音让花园地面发光，中音让花朵依次开放，孩子能同时看见两种音乐工作。

**真正学到什么**

在已经熟悉的两小节里体验简单的双手分工，而不是一边认新谱、一边学新节奏。

### TH08 会唱歌的大家园

**开场画面**

两颗星球的密封通道已经接通，只差最后一次完整演出让花园和远端月亮前哨同时亮起来。系统沿用孩子刚才成功的路线，不要求手动选择“简单”或“困难”。

**角色说**

“用我们刚学会的方法，让花园唱起来！”

**孩子做什么**

接力路线重复 TH05 的两小节；准备好的孩子重复 TH07 的合奏版。两种路线使用相同音符和相同故事结尾。

**完成时**

远端月亮前哨和整条桥依次亮起，生态侧的桥口变成花园小路。星芽从中继台走下、咚咚从地基站走上，两人在可呼吸花园中央 C 的会合灯旁击掌；不把无头盔角色画在开放太空桥中央。花园开放后画面自然停留，让孩子看成果，不弹出“关闭”或“下一关”对话框。

**真正学到什么**

把音名、唱名、键位、上下谱表、左右轮流和可选的同时弹奏放进一段完整音乐经历。

## 大人怎样知道孩子是真的会了

- **玩过**：在明显提示下完成一次，故事可以继续。
- **比较稳定**：减少亮键和颜色后仍能完成，错误不超过规定次数。
- **低音会了**：不仅按到同名音，还按在正确的低音八度。
- **读谱会了**：看谱位找到键，不能一直靠恐龙颜色或发光位置猜。
- **左右接力稳定**：按提示轮流完成，最多漏一次换手。
- **双手练习中**：能尝试一起落地。除非家长或老师实际观察，否则不能写“左右手技术已掌握”。

## 我作为普通观看者的直观意见

### 现在讲得通的地方

1. 主线已经清楚：搭自己的家、出发、听到陌生声音、找到朋友、两个家相连。咚咚不再像中途硬塞进来的新角色。
2. 第四章是目前最有吸引力的一章。先听声音、再见剪影、最后完整出现，孩子有继续玩的理由。
3. 教学关系不再只靠颜色。每个音会逐步连到唱名、字母名、黑键位置、谱位和声音。
4. 第五章把“双手”解释成两个朋友合作，比直接说“现在练左手右手”更自然。
5. 接力版和合奏版有同一个结局，能避免小孩子因为做不到双手同时而觉得自己选了差的路线。

### 我仍然会担心的地方

1. 星芽已经锁定为原创“星芽龙”，并补齐完整气密探索服；后续风险不再是“要不要戴头盔”，而是运行素材能否稳定保持三颗头芽、完整尾套、无胸灯战甲感，以及角色本体和穿服状态之间的同一身份。
2. 咚咚必须做到“稳重可爱”而不是“笨重滑稽”。如果动作太慢、颜色太暗，孩子可能不喜欢它。
3. 低音谱表一口气出现五条线仍可能让 4 岁孩子紧张，所以 LP08 第一画面必须只出现一个当前落脚垫，不能同时铺满答案。
4. TH06-TH07 对部分 4-6 岁孩子仍然太难。它们只能是奖励邀请，不能挡住故事结局。
5. 文字脚本再短也不能代替配音、动作和声音。真实孩子如果需要大人逐句读，说明画面没有完成自己的工作。

### 你看原型时可以直接问的六个问题

1. 三秒内能不能看出谁需要帮助、缺了什么？
2. 不读字，能不能从恐龙动作和画面变化猜到下一步？
3. 点对以后，世界有没有发生明显而具体的变化？
4. 点错以后，孩子有没有知道自己按了什么、应该去哪里找？
5. 这一关学的是声音、键位、谱位还是手的轮次，是否只新增了一件事？
6. 结束时孩子是想看看新变化，还是只是在等“下一关”按钮？

只要其中两项连续答不上来，就不要继续堆素材或关卡，应该先回头改这一关的画面和动作。

## 在正式制作前还必须做的事

- 请一位幼儿钢琴老师检查低音区、谱位、手型提示和两小节曲子。
- 先做两次短样课：第一次是 LP01、LP02、LP03；第二次是 LP07、只含 Do-Re-Mi 的 LP08-mini 和 LP10-mini。迷你谱桥不记录完整掌握。
- 找 3-5 名 4-6 岁孩子分别体验“开始、点错、恢复、完成、自然停下”。
- 记录孩子真正看的是声音、恐龙动作、谱位、黑键小地图还是文字。
- 根据观察修改后，才扩展剩余 LP 和 TH 关卡，并制作最终角色动作与场景美术。
