# 项目记忆

## 项目目标
开发并部署儿童钢琴启蒙 Web 应用（小恐龙星际钢琴工作坊），支持 iPad 及多端全屏运行，提供视唱练耳、五线谱认知与钢琴互动练习体验。

## 技术架构
- 语言：JavaScript (ES6+), HTML5, CSS3
- 框架：原生 Web 技术栈 (Vanilla JS + Web Audio API + PWA/Web Manifest)
- 部署：GitHub Pages

## 核心规范
- 界面适配 iPad 与各分辨率屏幕，杜绝元素悬空与视觉碎裂
- 代码遵循模块化与原生无依赖规范
- 静态资源路径与部署保持一致
- 声学优先级规范：真实钢琴音色为主（Gain>=0.34, 时长>=1.4s），UI音效为辅（Gain<=0.10且避让延迟）
- 关卡重玩与微循环规范：已通关节点始终允许点击重练，单关支持“示范-盲找-三连律动”渐进强化
